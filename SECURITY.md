# Sicherheitsprobleme melden

Vertrauliche Probleme nicht mit privaten Daten in einem öffentlichen Issue
melden. GitHub Private Vulnerability Reporting verwenden, wenn es im
Repository aktiviert ist. Andernfalls zunächst ein Issue ohne sensible
Details eröffnen und einen vertraulichen Kontaktweg vereinbaren.

Keine Tokens, Apple-Paarungsdateien, Kartennummern, Wohnadressen oder
Gerätekennungen anhängen. Der Kartenbild-Editor benötigt keine Zahlungsdaten.

Die App bietet keine Fernsteuerung über das Internet. Die Browser-Vorschau
bindet nur an 127.0.0.1. Netzwerkdienste für Karten und Routen sind in der
README dokumentiert.
