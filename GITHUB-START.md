# GitHub-Projekt

Repository: https://github.com/LorenzHPP/LarpStudio

Für den Upload wird eine GitHub-Verbindung mit Schreibrechten für dieses
Repository benötigt. Inhalte, Workflows und Actions müssen freigegeben sein.
Das Projekt ist öffentlich und enthält nur einen öffentlichen Beispielort.

Nach erfolgreichem Upload: Actions → Windows app → Run workflow.
Das Artefakt Larp-Studio-Windows vollständig entpacken und Larp Studio.exe
starten. Apple-Treiber und WebView2 bleiben erforderlich.
